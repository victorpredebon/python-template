# Security Policy

## Supported versions

Only the latest release (the most recent `vX.Y.Z` tag on `main`) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/victorpredebon/python-template/security/advisories/new).

Include what is affected (workflow, hook, dependency, code), how to reproduce it and the impact.
You should get a first answer within 7 days.
